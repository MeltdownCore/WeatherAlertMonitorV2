# WeatherAlertMonitorV2
An app that warns you about Weather Alerts.

# Why was WeatherAlertMonitorV2 created?
Weather Alert Monitor V2 was created to possibly save lives. Before I even had the idea to create this app, there were multiple storms that I was never warned about and many things were damaged. This app can help prevent that. It will warn you about Weather Alerts, attempting to keep you safe.

# Please note this was COMPLETLY Vibe codded with AI
I don't know much about coding yet but I this, in my book, is good use of AI.

# How to download?
Its really simple to download the app, the app runs with python but python is packaged inside the exe. so you shouldn't need to do anything. Just hit download and you should be set to be protected!

# Setup
The app will start with random Zip Code. Insert your Zip Code and you are good to go! Please keep in mind this app will only work in the USA. Sorry!

# Features
Weather Alert Monitor contains a few warnings warning sounds. Feel free to change them to make your own. If you do not wish, you don't have to do anything, everything is set up for you.
Weather Alert Monitor contains a FREE radar feature! Check previous and future weather with the radar!

Thanks for reading and I hope you enjoy the app!
